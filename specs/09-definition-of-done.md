# Fool Authentication API — Definition of Done

The initial vulnerable application is complete when:

- Node.js application starts locally.
- TypeScript compilation works.
- SQLite initializes automatically.
- Seed users are created automatically.
- User registration works.
- Login works.
- JWT authentication works.
- Protected user endpoints work.
- Health endpoint works.
- OpenAPI specification is available.
- The application produces reproducible security findings.
- Intentional vulnerabilities are documented.
- Automated functional tests pass.
- README explains setup and security-testing workflow.

Implementation decisions should prioritize making this cycle simple, observable, and repeatable.
